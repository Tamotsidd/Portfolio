# 🎨 Personal Portfolio Website

> **Live Website:** https://tamotsidd.github.io/Portfolio/

A modern and responsive personal portfolio website designed to showcase my work, skills, experience, and creative projects as a UI/UX Designer.

The website focuses on a clean, minimal, and user-friendly interface with smooth navigation and an engaging presentation of selected work.

---

## ✨ Features

- Responsive portfolio website
- Modern and minimal UI
- About Me section
- Skills and expertise
- Selected Work section
- Interactive project navigation
- Project showcase with external links
- Certificate with pdf files of them
- Contact section
- Responsive design for different screen sizes
- Smooth and intuitive user experience

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript
